# hydracept-status

Public status page for [status.hydracept.com](https://status.hydracept.com).

Probe logic and UI are developed in the private Hydracept monorepo and synced into this repository on demand. Scheduled probes and GitHub Pages deploy run here only (free tier for public repos).

See [GO-LIVE.md](./GO-LIVE.md) for launch order, repository variables on **both** repos, and DNS safety gates.
